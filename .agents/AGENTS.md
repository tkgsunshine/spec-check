
# Project Specific Rules - spec-check

## 🚫 Vercelデプロイに関するレギュレーション
- **自動デプロイの禁止**: 作業のたびに `npx vercel` やデプロイコマンドを自動実行しないこと。Vercelの1日100回デプロイ制限を回避するため。
- **デプロイタイミング**: ユーザーから「デプロイして」「本番反映して」等の**明確な指示があった場合のみ**デプロイを実行すること。
- **通常の開発フロー**:
  1. コード変更・機能実装
  2. `npm run build` でビルドエラー0件を検証
  3. `git commit` でローカルに差分を保存
  4. ユーザーからのデプロイ指示を待つ
